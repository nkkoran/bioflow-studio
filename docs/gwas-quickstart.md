# GWAS Quickstart

1. Connect to Rorqual from the top bar.
2. Drag an input genotype file node onto the canvas.
3. Add a PLINK2 association node.
4. Connect genotype, phenotype, and covariate inputs.
5. Configure phenotype and covariate columns in the inspector.
6. Validate, preview scripts, then run.

Expected outputs land in the run output folder configured during onboarding.

Common issues: missing Slurm account, disconnected SSH session, file paths that use local paths instead of remote cluster paths.
