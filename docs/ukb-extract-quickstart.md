# UKB Extract Quickstart

The DNAnexus RAP workflow is developer-gated for the beta. Unlock Developer Options in Settings with the development PIN, then configure DNAnexus.

1. Open Settings, unlock Developer Options, and select DNAnexus.
2. Save a DNAnexus token and choose a default project.
3. Install or refresh the bundled UKB extract applet.
4. Add the UKB Data Extraction node or use Quick UKB Extract.
5. Choose fields, output folder, and instance type, then run.

If the DNAnexus section is absent, RAP features are intentionally locked for this session.
